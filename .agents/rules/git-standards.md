# Padrões de Git Commit & Memory Palace do Gideon

Todo commit no repositório DEVE ser escrito em inglês seguindo a convenção estrita:

- `feat:` Nova funcionalidade
- `fix:` Correção de bug
- `perf:` Melhoria de performance (tempo, render, memória)
- `refactor:` Refatoração sem mudança comportamental
- `test:` Inclusão ou ajuste de testes
- `ci:` Integração contínua e automações
- `docs:` Documentação
- `chore:` Manutenções secundárias e dependências
- `duel:` Comparações e benchmarks arquiteturais competitivos

## Atualização do Memory Palace
Toda alteração de arquitetura ou regra de negócio deve ser registrada com data, agente e contexto no arquivo `MEMORY_PALACE.md`.
